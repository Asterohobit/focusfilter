# Blocker Extension

A Firefox/Chrome browser extension designed to block unwanted content.

## Features

- Content blocking functionality -> currently only for YouTube Shorts
- Popup UI with on/off toggle to enable or disable blocking without reloading the page

## Planned

- Extension UI
- Support for additional websites

## Installation

1. Clone the repository
2. Load the extension in your browser
3. Configure blocking preferences
